# luci-app-vnt2

OpenWrt LuCI application for managing VNT2 CLI/CTRL/Web services.

## Package Name

The actual package name inside OpenWrt package management is always:

- `luci-app-vnt2`

This is the name you should search for in `System -> Software`, and the name used by `opkg` / `apk`.

## Release Files

GitHub Release assets keep the standard filenames generated by OpenWrt build output.
Their filenames may include version, release and architecture suffixes, but the package name prefix is always:

- `luci-app-vnt2`

Examples:

- `luci-app-vnt2_2.0.40-r1_all.ipk`
- `luci-app-vnt2-2.0.40-r1.apk`

## Install

### OpenWrt 24.10.x

Upload the `.ipk` file to the router, for example into `/tmp/`, then install:

```sh
opkg install /tmp/luci-app-vnt2*.ipk
opkg info luci-app-vnt2
opkg list-installed | grep luci-app-vnt2
```

### OpenWrt 25.12.0

Upload the `.apk` file to the router, for example into `/tmp/`, then install:

```sh
apk add --allow-untrusted /tmp/luci-app-vnt2*.apk
apk info luci-app-vnt2
```

## Build In OpenWrt

Place this project into OpenWrt `package/` or into a custom feed, then compile:

```sh
git clone <your-repo-url> package/luci-app-vnt2
make menuconfig
make package/luci-app-vnt2/compile V=s
```

After the build:

- OpenWrt 24.10.x produces `.ipk`
- OpenWrt 25.12.0 produces `.apk`

## LuCI Entry

After installation, open:

```text
VPN -> VNT2
```
